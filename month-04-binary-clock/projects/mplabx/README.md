# MPLAB X projects

Complete MPLAB X projects for this month's PIC builds: **device PIC16F18446**, **compiler XC8**, tool **PICkit 3**.

Each project is a folder ending in `.X`. Open it with **File → Open Project** in MPLAB X. A project is added here only **after** its build has compiled and run on a real board.

| Build                              | Project folder           | Status           |
| ---------------------------------- | ------------------------ | ---------------- |
| `code/build-1-blink/main.c`        | `build-1-blink.X`        | not yet exported |
| `code/build-2-rtc-hello/main.c`    | `build-2-rtc-hello.X`    | not yet exported |
| `code/build-3-binary-clock/main.c` | `build-3-binary-clock.X` | not yet exported |

How projects are added: see the [projects and hardware guide](../../../maintainer/PROJECTS_AND_HARDWARE_GUIDE.md).
