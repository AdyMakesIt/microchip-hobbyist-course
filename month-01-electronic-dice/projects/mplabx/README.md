# MPLAB X projects

Complete MPLAB X projects for this month's PIC builds: **device PIC16F18857 (for the pic-* builds)**, **compiler XC8**, tool **PICkit 3**.

Each project is a folder ending in `.X`. Open it with **File → Open Project** in MPLAB X. A project is added here only **after** its build has compiled and run on a real board.

| `code/pic-3-dice/main.c`   | `pic-3-dice.X`   | not yet exported |
