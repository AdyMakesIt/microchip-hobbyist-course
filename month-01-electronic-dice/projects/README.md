# Ready-to-open projects

Complete, working projects for every build in this month, so you can open one and run it without typing.

| Folder                        | What is in it                                                                                        |
| ----------------------------- | ---------------------------------------------------------------------------------------------------- |
| [`mplabx/`](mplabx/README.md) | MPLAB X projects for the PIC builds (added after each has been bench-tested)                         |
| [`platformio/`](platformio/)  | PlatformIO projects for the ATmega328P builds: open the folder in VS Code and press Build and Upload |

The source on the build pages comes from `../code/`; these projects always hold an identical copy (checked automatically).
